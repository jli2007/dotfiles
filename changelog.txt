INSTALLED

  starship 1.27.0, fzf 0.74.5                                  (~/.local/bin)
  font-jetbrains-mono-nerd-font                                (homebrew cask)

  Note: this Mac runs macOS 14.6, and homebrew no longer ships prebuilt
  binaries for it ("no longer builds bottles for this configuration"), so
  brew compiles everything from source. starship and fzf were installed as
  official prebuilt release binaries instead, to avoid compiling Rust and Go.
  brew will not update those two; re-download the release asset to upgrade.

LAYOUT
  Real files live in ~/dotfiles and are symlinked into place:
    ~/.config/tmux          ~/.config/nvim
    ~/.config/ghostty       ~/.config/starship.toml
  Editing either path edits the same file. No rebuild step.
  ~/.zshrc stays a real file; it sources one block from zsh/dotfiles.zsh.
  install.sh sets all of this up on a fresh machine. It is idempotent:
  it only adds what is missing and never overwrites a real file.
  .gitignore blocks .env, *.pem, *.key, ssh keys, auth.json and .zshrc
  from ever being committed.

  added   starship prompt

  added   syntax highlighting, sourced last (required order)
          recolored: stock paints every unrecognised word red, which hits
          every half-typed line. Plain text is white; a recognised command
          turns green, so the signal is "it went green", not "it's red".
  added   alias ..='cd ..' and ff='fastfetch'

  SPLIT INTO TWO LAYERS
    Functional bits load in every terminal: fzf keys, autosuggestions,
    aliases. Visual bits load in ghostty ONLY: starship, syntax
    highlighting colors, fastfetch.
    Why: the prompt colors are 24-bit hex and Terminal.app has no
    truecolor support - it renders the escapes as garbled highlight
    blocks. Outside ghostty the prompt falls back to plain ANSI
    (%F{green}%n@%m%f  %F{cyan}%~%f), which works anywhere.
    Detection: $GHOSTTY_RESOURCES_DIR / $TERM_PROGRAM. Those are
    EXPORTED, so tmux panes inherit them - fastfetch additionally
    checks $TMUX so it does not fire on every split.

  Every feature is guarded by an existence check, so a missing tool is
  skipped instead of erroring on every shell start.
  Brew paths are hardcoded to /opt/homebrew rather than $(brew --prefix),
  which would spawn a subprocess on every shell start.

STARSHIP        .config/starship.toml
───────────────────────────────────────────────────────────────
  Reproduces the old prompt, plus git:
    jamesli@mbp        username + a literal short machine label
    directory          truncated to 3 levels, or to the repo root
    git branch         grey
    git status         yellow; ! = uncommitted changes
    command duration   grey, only shown when over 500ms
    ❯                  green, red when the last command failed

  Colors are explicit hex, NOT the ANSI names "green"/"cyan". The Rose Pine
  Moon terminal theme remaps the ANSI palette:
      ANSI green -> #3e8fb0  (blue-teal)
      ANSI cyan  -> #ea9a97  (salmon)
      ANSI red   -> #eb6f92  (pink)
  so asking for "cyan" gets salmon. Hex bypasses the remap:
      #9ece6a green   #7dcfff cyan   #eb6f92 error

  "mbp" is a literal in the [hostname] format; edit it to taste.

FASTFETCH       .config/fastfetch/config.jsonc
───────────────────────────────────────────────────────────────
  Stock output is 20 rows and its longest values run 55-62 chars. The
  big apple logo costs ~37 columns, so in a half-width tmux pane the
  long rows wrap mid-word. Terminals cannot render one command at a
  smaller font, so the only lever is less text.

  removed   Host        the model string is ~58 chars and the only
                        short placeholder is "Mac15,6". The title and
                        OS/CPU rows already identify the machine.
  removed   WM Theme    always "Multicolor (Dark)" - says nothing
  removed   Cursor      cursor fill/outline/size - never actionable

  shortened Display     dropped scaling and physical size, kept [type]:
                        it is the only way to tell the built-in screen
                        from an external one while docked
  shortened Font        dropped the user font, kept the system one
  shortened GPU         dropped core count, clock and [Integrated]
                        (always integrated on apple silicon)
  shortened Disk        dropped "- apfs [Read-only]" - both constant on
                        modern macOS. NOT pinned to "/", so real
                        external drives still appear. A pile of disk
                        rows means dmgs are still mounted; eject them.

  Everything else is stock. Longest line is now 83 of 90 columns.
